# Third-party materials

## Existing project code

The P1+M+ dependency closure originates in [cafka/rpi5-explorer](https://github.com/cafka/rpi5-explorer), developed with Kiro. Exact paths, commit and hashes are recorded in `provenance/source-lock.json`. The upstream tree did not provide a root open-source license at the reviewed commit. Reuse in this independent project follows the owner's explicit instruction; it is not based on an assumed upstream public license. Original source comments are preserved.

## Development dependency

`sharp` 0.35.5 is Apache-2.0 licensed. It is installed through npm, with its own license and bundled dependency notices. Its native image libraries retain their respective licenses. This repository does not copy or relicense those binary packages. See [sharp's license](https://github.com/lovell/sharp/blob/v0.35.5/LICENSE) and the installed package notices. The lockfile records dependency versions and integrity.

## Excluded assets

Stage 2 installs the official Firebase JS SDK 13.4.0 (Apache-2.0), esbuild 0.28.2 (MIT), and Playwright 1.65.1 (Apache-2.0) through npm. Their licenses remain in their installed packages. The lockfile pins all package integrity values; only imported Firebase app, App Check and AI modules enter the browser bundle. No Firestore or gRPC code is imported by this application. An override pins transitive `@grpc/grpc-js` to patched 1.13.6 to address GHSA-m9gg-hp2v-232j and GHSA-f596-whhp-79r4, without downgrading Firebase. The final npm audit reports zero vulnerabilities. This does not certify dependencies against future advisories.

The historical prepared video frames, Raspberry Pi reference image, photo-derived NCC/orientation arrays and inherited board catalogs are not published here. Necessary local regression assets are identified by hashes and imported from a user-authorized source into `.local/fixtures/`, which is ignored by Git. Access to a source image is not evidence of redistribution permission. No photos or derived visual arrays should be force-added before rights and attribution are reviewed.

Synthetic unit-test signals are generated by code and contain no real photographs. Experiment reports contain numerical outputs and provenance, not image pixels.
