# Catalogue assets

Coral model and surface derivatives: Google Coral mechanicals/electricals, Apache-2.0. See `Coral-LICENSE.txt`. Converted to glTF, and silk/contact layers rasterized for Inside the Circuit. STEP source commit `be47f619f5cb43b1fb19973abe988b733ed16560`; electrical source commit `7250d49a08a296fb9aaabb2415b6c0e73355914a`. Two degenerate faces excluded as documented in the preserved CAD audit. Original CAD geometry otherwise unchanged.

Raspberry Pi CAD and graphics: Raspberry Pi Ltd, MIT; original notice in `experiments/cad-viewer/CAD_LICENSE.txt` and graphics directory.

Arduino PCB-derived contacts and artwork: CC BY-SA 4.0; attribution in their asset directories. The Nano STEP conversion is NOT distributed in this seed: the restore recipe downloads the original Arduino archive locally.

Pimoroni photographic pixels and generated textured model are NOT distributed here. The local restoration recipe downloads two official images with exact hashes, then regenerates the educational model using stored observations. These observations are historical model proposals, not a fresh inference or verified manufacturing geometry. Source photograph redistribution remains uncleared.
